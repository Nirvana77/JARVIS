# JARVIS (the 2026 rebuild, `python -m jarvis`) — the all-in-one box, and the
# brain of a brain/edge split.
#
#   python -m venv .venv
#   source .venv/bin/activate
#   pip install -r requirements.txt
#
# Needs PortAudio for sounddevice:
#   sudo dnf install portaudio-devel     # Fedora
#   sudo apt install portaudio19-dev     # Debian/Ubuntu
#
# Three other requirement sets exist, on purpose — each runs in its own venv so
# a wedged model is one process to restart:
#   requirements-edge.txt            the audio satellite (no models at all)
#   services/whisper/requirements.txt the warm transcription service
#   services/voder/requirements.txt   the warm speech service
#
# The legacy `main.py` / `libs/` path has its own (TensorFlow-era) dependencies
# — see README.md. Nothing here is needed for it, or it for this.
#
# Lower bounds, not pins: these are the versions this was built and tested
# against (2026-09-25, Python 3.14).
